# Manual Software Testing | BLUBOHO Project

## Project Overview

This repository showcases the manual software testing documentation and quality assurance activities performed for the **BLUBOHO** project.

The project demonstrates a structured approach to software testing, covering test analysis, test case development, defect documentation, test metrics, and test reporting. It reflects practical knowledge of QA methodologies and the Software Testing Life Cycle (STLC), with an emphasis on maintaining clear, organised, and traceable testing documentation.

## Testing Scope & Activities

The following QA activities are covered in this project:

- **Requirement Analysis:** Reviewing project requirements to identify testable functionalities and testing scope.
- **Test Documentation:** Preparing structured test scenarios and test cases based on application requirements.
- **Test Execution:** Validating application functionality against expected results.
- **Defect Management:** Documenting identified issues through structured bug reports.
- **Test Metrics:** Organising testing-related metrics to monitor testing progress and results.
- **Test Reporting:** Preparing a consolidated test report to communicate testing outcomes.
- **Test Planning:** Creating a mind map to organise project components and testing activities.
